============================================================
0. OBJECTIF GÉNÉRAL
============================================================

Je veux créer une application mobile de gestion de boutiques et de produits.

L'application doit être :

- réellement fonctionnelle ;
- testable avec Expo Go ;
- utilisable depuis plusieurs téléphones ;
- connectée à un backend hébergeable sur Vercel ;
- connectée à MongoDB Atlas ;
- capable de stocker les images des produits dans Vercel Blob ;
- conçue pour être améliorée plus tard sans devoir refaire toute l'architecture.

Architecture finale obligatoire :

APPLICATION REACT NATIVE
installée/testée sur les téléphones
            |
            | HTTPS REST API
            v
BACKEND NODE.JS + EXPRESS
hébergé sur Vercel
            |
            +----------------------+
            |                      |
            v                      v
      MongoDB Atlas           Vercel Blob
      données                 images
      utilisateurs
      boutiques
      produits

Tous les téléphones doivent utiliser le même backend.

Ainsi :

Téléphone A
Téléphone B
Téléphone C
     |
     v
Même backend Vercel
     |
     v
Même MongoDB Atlas

Ils doivent donc retrouver les mêmes :

- utilisateurs ;
- boutiques ;
- produits ;
- modifications ;
- suppressions ;
- images.

13. JWT
============================================================

Créer :

userId

2. vérifier signature JWT ;
3. extraire userId ;
4. charger User depuis MongoDB ;
5. vérifier User existe ;
6. vérifier isActive ;
7. utiliser le role provenant de MongoDB ;
8. utiliser shopId provenant de MongoDB.

NE PAS faire confiance à :

27. LIMITE IMAGE VERCEL
============================================================

IMPORTANT :

Une requête Vercel Function ne doit pas recevoir de gros fichiers arbitraires.

Pour ce MVP utiliser :

MAX_PRODUCT_IMAGE_SIZE = 3 MiB

et PAS 5 MiB.

Cela laisse une marge pour :

- multipart/form-data ;
- JSON ;
- headers ;
- autres champs de la requête.

Frontend :

refuser si image clairement > 3 MiB lorsque la taille est disponible.

Backend :

TOUJOURS appliquer la vraie limite.

Multer :

memoryStorage()

limits.fileSize = 3 MiB

NE PAS utiliser :

diskStorage()

NE PAS écrire l'image dans :

/uploads

NE PAS utiliser le filesystem Vercel comme stockage persistant.
